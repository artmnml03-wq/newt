# NEWT

Сайт про музыку: шесть секций с анимацией по скроллу, плеер, форма подписки и поп-ап.
Vite + GSAP, без фреймворка.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # готовый сайт в папке dist
```

## Структура

- `index.html` — вся разметка (шесть секций, меню, поп-ап)
- `src/styles/` — стили: `tokens.css` (цвета и шрифты из UI-кита), секции, `responsive.css` (планшет и телефон)
- `src/js/` — анимации и логика: `stages.js` (секции, которые накрывают друг друга), `player.js`, `nav.js`, `cursor.js` и т. д.
- `public/` — картинки, шрифты, видео и аудио

## Музыка и видео

Файл кладут в `public/audio/` (или `public/video/`) и указывают путь в `data-src` карточки плеера в `index.html`.
Сейчас там демо-треки, сгенерированные для проверки плеера, это не настоящая музыка.

## Публикация на GitHub Pages

При каждом пуше в ветку `main` сайт собирается и публикуется автоматически (`.github/workflows/deploy.yml`).
Один раз нужно включить: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
Адрес будет `https://<имя-пользователя>.github.io/<название-репозитория>/`.
