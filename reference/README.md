описание анимацией сайта 
1 секция - бегущая строка - позиция фиксированная, остальной контент кроме бегущей строки и меню скроллится горизонтально, смена контента из опасити 40%, когда контент сменился полностью, появляется вторая секция
2 секция анимация - новая секция перекрывает пред секцию + анимация букв + смена цвета фона и элементов - пример по ссылке https://www.blimp.gr/
3 секция - новая секция перекрывает пред секцию, остальные эл в opacity 20%, карточки скроллятся по горизонтали + постепенно проявляются из опасити 20% в 100%
4 секция - появление текста из опасити 30% в 100% + bg video зафиксировано
5 секция - анимация при скролле как в примере https://www.rhythminfluence.com/?ref=landing.love
6 секция - элементы проявляются из opacity 30 % в 100% + увеличивается изображение
pop-up появляется спустя 10 сек после загрузки  сайта

В каждой папке есть папка assets, откуда нужно брать картинки для секции, так же в каждой папке есть референт как должна выглядеть секция, скриншот лежат не в папке assets
Есть так же UI kit это там где указано какие размеры заголовков, текста и так далее использовать, так же какие цвета и отступы
